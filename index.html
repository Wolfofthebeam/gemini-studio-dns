💡 Ошибка «origin_mismatch»? Как включить Google Диск для вашего GitHub сайта за 1 минуту

Google строго проверяет адреса сайтов (Origin) для защиты ваших файлов. Чтобы вход заработал на GitHub Pages (https://wolfofthebeam.github.io):

  1. Перейдите в консоль Google: Google Cloud Credentials (Кликните сюда)
  2. В списке «Идентификаторы клиентов OAuth 2.0» кликните по вашему клиенту (Web Client).
  3. В блоке «Разрешенные источники JavaScript» (Authorized JavaScript origins) нажмите «+ ДОБАВИТЬ URI».
  4. Вставьте адрес вашего сайта:
    https://wolfofthebeam.github.io (строго без слэша / в конце!)
  5. Нажмите синюю кнопку «Сохранить» внизу.
✨ Это бесплатно, без привязки карт. Через 1-2 минуты обновите эту страницу — вход сразу откроет ваш Google Диск!
